What LazyRelay does

One place to schedule, publish and check your posts, built around a simple idea: a post is only done when it is really live.

Scheduled posting to 17 platforms

Facebook, Instagram, TikTok, Pinterest, YouTube, LinkedIn, Threads, Mastodon, Bluesky, Telegram, Discord, Tumblr, WordPress, dev.to, Hashnode, Lemmy and Slack. LazyRelay checks every 30 seconds and sends posts when they are due.

Proof-of-Publish

After publishing, LazyRelay independently checks with the platform that each post is live, instead of trusting the first accepted response. A post it cannot confirm is flagged in your dashboard, not hidden.

Comments in one stream

LazyRelay reads comments on the posts you publish through it from 9 platforms into one place. It does not track mentions elsewhere on the web, and comments are kept for up to 30 days.

Free to start

The Free plan costs $0 and needs no credit card. AI-agent, MCP and API access is included on every plan, including Free.

Built for AI agents and developers too

A REST API described in OpenAPI 3.1, a hosted MCP server with 27 tools, a Node SDK and command line tool, and an n8n node. Connect an AI assistant, an editor or your own code.

Frequently asked questions

Direct answers about security, AI agents, AI use and failed posts. Select a question to open it.

How does LazyRelay store the login tokens of my connected social accounts?

Login tokens are stored in Supabase Vault, which encrypts them at rest. The database keeps only a reference ID for each secret, and the functions that read or write them can be run only by LazyRelay's server, not from a browser or a signed-in user session. When you disconnect an account, the stored login is overwritten.

How does LazyRelay's hosted MCP server authenticate AI agents?

The /mcp endpoint accepts OAuth 2.1 bearer tokens and checks each one against the identity provider's published signing keys (JWKS, ES256). A token must be issued for the MCP server itself, so ordinary dashboard session tokens are rejected there. API keys are the other way in, for the REST API and the local npm package.

Which AI tools can connect to LazyRelay?

LazyRelay has setup pages for 15 tools: Claude, ChatGPT, Perplexity, Notion, Manus, OpenClaw, Cursor, Windsurf, Antigravity, Codex CLI, Gemini CLI, VS Code, n8n, Make and Raycast. For n8n there is a community node package, n8n-nodes-lazyrelay. Zapier is a private, invite-only app.

Which AI model does LazyRelay use, and what does it do with my comments?

Comment and direct message sorting, plus the optional caption, hashtag and idea helpers, call Anthropic's Claude Haiku 4.5 directly from LazyRelay's servers, using LazyRelay's own API key. Comment and reply text is kept out of LazyRelay's analytics. LazyRelay never replies to a comment on its own, and AI-suggested replies are not yet available.

What happens when a platform keeps failing?

Every post is checked after publishing. A failed post that could still succeed is retried up to 3 times, after waits of 2, 4 and 8 minutes. If a platform returns 5 failures in a row, LazyRelay pauses posting to that platform for 5 minutes, then resumes. This protects your queue from repeated errors; it does not replace each platform's own content rules.
