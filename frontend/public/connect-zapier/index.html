How to Connect LazyRelay to Zapier

Wire LazyRelay into 9,000+ other apps — Google Sheets, Slack, Shopify, WordPress, and more — without writing any code.

What you can do with it

Once connected, you can build automations ("Zaps") like:

  1. A new row in a Google Sheet content calendar → automatically schedules a LazyRelay post.
  2. A new blog post on your site → automatically creates a LazyRelay post promoting it.
  3. A LazyRelay post gets confirmed live → logs it into a spreadsheet or Slack channel.
  4. A new comment on one of your posts → pings your team so someone can reply.

Setup

  1. In your LazyRelay dashboard, go to Settings → API Keys and create a new key. (This requires a paid plan — Starter, Pro, or Business.) Copy the key somewhere safe — it's only shown once.
  2. Open LazyRelay's Zapier app using this link: Connect LazyRelay on Zapier. This adds LazyRelay to your own Zapier account.
  3. Start building a Zap, choose LazyRelay, and when it asks you to connect an account, paste in the API key from step 1.
  4. Pick a trigger (like New Post Published or New Mention) or an action (like Schedule Post), and build out the rest of your Zap as normal.

LazyRelay's Zapier integration is currently invite-only rather than listed in Zapier's public app directory — the link above is how you connect to it either way.

Don't have an API key yet? Generate one from your dashboard's Settings tab — available on every paid plan (Starter, Pro, Business, Agency, and Agency Plus).
