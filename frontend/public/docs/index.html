API and MCP server

Everything below is real and live today: the same API LazyRelay's own dashboard runs on. Already have an account? The same docs live inside your dashboard's API Keys tab, with no need to sign back in.

Authentication

Generate a key from your dashboard: More → API Keys → Create key. The raw key is shown once, so copy it immediately. Send it as a bearer token on every request:

HTTP header
Authorization: Bearer lzr_live_your_key_here

Each key acts as your account. Treat it like a password. Creating or revoking keys always requires signing in to the dashboard directly; a key can never be used to mint or revoke other keys, so a leaked key can't lock you out.

Base URL

Base URL
https://lazyrelaylazyrelay-backend.onrender.com/api

Endpoints

GET/social-accounts

List your connected social accounts

POST/scheduled-posts

Schedule a post to one connected account

Request body (JSON)
{
  "socialAccountId": "…",
  "content": "Your post text",
  "scheduledFor": "2026-08-10T09:00:00Z",
  "mediaUrl": "https://example.com/image.jpg"
}
GET/scheduled-posts

List upcoming and recent posts, with status and Proof-of-Publish verification

DELETE/scheduled-posts/:id

Cancel a pending post

GET/analytics/summary?days=30

Post counts, verified-live rate, per-platform breakdown, engagement totals

GET/mentions

Recent comments on your posts, where the platform supports reading them

POST/mentions/reply

Reply to a comment surfaced by GET /mentions

Request body (JSON)
{
  "postId": "…",
  "commentId": "…",
  "text": "Thanks so much!"
}

Using this from an AI agent: the MCP server

If you're connecting an AI agent (Claude Desktop, Claude Code, Cursor, or anything else that speaks MCP) rather than writing HTTP calls by hand, use LazyRelay's own MCP server instead of calling the API directly. It wraps every endpoint above as a real tool the agent can call. Every tool, with its exact description and input schema, is listed in the MCP tool reference. For the tools grouped by job, webhook signing, rate limits per plan and package versions, see MCP tools, webhooks and limits.

MCP config, local package
{
  "mcpServers": {
    "lazyrelay": {
      "command": "npx",
      "args": ["-y", "@lazyrelay/mcp-server"],
      "env": { "LAZYRELAY_API_KEY": "lzr_live_your_key_here" }
    }
  }
}

This runs locally on your own machine using your own API key, so there's nothing to host. See the package README for the full tool list.

No install: the hosted MCP server

Prefer not to install anything, or connecting from claude.ai rather than a desktop app? LazyRelay also runs a hosted MCP server. Instead of an API key, you sign in with your LazyRelay account the first time you connect. Same 27 tools, same account, nothing to run locally.

Hosted MCP URL
https://lazyrelaylazyrelay-backend.onrender.com/mcp

In Claude, go to Settings → Connectors → Add connector, choose Remote, and paste the URL above. You'll be asked to sign in and approve access, the same way you'd approve any other app. For MCP clients that use a config file instead:

MCP config, hosted
{
  "mcpServers": {
    "lazyrelay": {
      "url": "https://lazyrelaylazyrelay-backend.onrender.com/mcp"
    }
  }
}

To stop a connected app from accessing your account, remove it from wherever you connected it (for example, your AI tool's connector settings).
