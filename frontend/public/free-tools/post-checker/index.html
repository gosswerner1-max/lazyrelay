Will My Post Fit?

Every platform has its own text limit and its own rules about images and video. Paste your post, say what media it has, and see which of 16 platforms it fits, and which it does not, before you schedule it.

How it works

For each platform you tick, the checker compares your text against that platform's limit and your media against what the platform accepts in one post. A green result means it fits. A red result tells you what to change. Where we could not verify a published limit, the checker says so and never makes up a number. Everything runs in your browser: your text is not sent anywhere or stored.

Platforms to check

Counts are estimates. Where the rules say a platform counts UTF-16 characters, graphemes or bytes, we count that way. For all others we use JavaScript string length, which can differ slightly from how the platform counts. Media rules cover how many files a single post can carry and whether images and video are allowed, not file size or length.

Frequently asked questions

Why does the same post count differently on different platforms?

Platforms do not all count text the same way. TikTok counts UTF-16 characters, Bluesky counts graphemes (what a person sees as one character, so an emoji is one), and YouTube's description limit is in bytes, so accented letters and emoji use more of it. This tool counts each platform the way its own documentation says where we could verify it, and otherwise uses plain JavaScript string length, which is an estimate.

Where do these limits come from, and are they always right?

The numbers come from the platform rules LazyRelay itself uses to check posts before scheduling, checked against each platform's published developer documentation. Some limits vary by account or server, such as Mastodon, where every server sets its own limit, so treat the result as a strong guide and not a guarantee.

Why does a platform say there is no limit we could verify?

For some platforms, such as Facebook Pages and LinkedIn, we could not find a published text limit. We show the character count and say so instead of guessing a number. That does not mean there is no limit, so keep very long posts in mind.
