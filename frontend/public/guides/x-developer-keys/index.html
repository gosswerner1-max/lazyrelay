Connect X With Your Own Developer Keys

About five minutes. You create a small X developer app that belongs to you, copy four keys from it, and paste them into LazyRelay.

How this works, and who pays

LazyRelay does not have an X account of its own to post with. Instead, you use your own X developer app, and X bills your own X developer account directly for each post. LazyRelay never pays for it and never sees your X balance. Connecting X this way is available on the Pro, Business, Agency and Agency Plus plans.

What X charges (check X for today's prices)

These are X's pay-per-use prices as we last read them. X sets them and can change them at any time, so always check X's own pricing page before you add credits.

What you postAbout what X charges
A plain text post$0.015
A post that contains a link$0.20

LazyRelay also checks that each post is really live after it is sent. That check is a request to X too, so it can use a small amount of credit on top of the price above.

The steps

  1. Create an X developer account. Sign in to X in your browser, then open the X Developer Console and sign up for a developer account. Use the same X account you want LazyRelay to post to.
  2. Add credits and set a spending limit. In the Developer Console, open billing, add a small amount of credit, and set a spending limit you are comfortable with. If your credits run out, X refuses new posts until you add more.
  3. Create a project and an app. In the Developer Console, create a project, then create an app inside it. Any name works.
  4. Set the app permission to Read and Write. Do this before step 6. Open your app's settings, find the user authentication (or app permissions) section, and choose Read and Write. If X asks for a callback address or website address on this screen, type your own website. LazyRelay does not use them.
  5. Open the Keys and tokens tab of your app.
  6. Generate your keys, in this order.
    1. Generate the API Key and API Secret (X may call them Consumer Key and Consumer Secret). Copy both.
    2. Then generate the Access Token and Access Token Secret. Check that X labels the Access Token as Read and Write. If it says Read only, go back to step 4, change the permission, then regenerate the Access Token. A token made before you changed the permission stays read-only.
  7. Paste the four keys into LazyRelay. In your dashboard open Social Platforms, choose the X tile, then Connect X. Paste the API Key, API Secret, Access Token and Access Token Secret, tick the box to confirm that X bills your developer account, and choose Check my keys. When it shows your handle, choose Save and connect.

If something goes wrong

What you seeWhat to do
"X did not accept these keys"Copy the four values again. Make sure the two secrets were not swapped and no spaces were copied with them.
A post fails and mentions credits or a spending limitAdd credits or raise the spending limit in the X Developer Console, then schedule the post again. LazyRelay does not retry these.
"Your X app needs Read and Write permission"Change the app permission to Read and Write, regenerate the Access Token and Access Token Secret, and paste the new keys into LazyRelay.
X stops accepting your keys laterRegenerating keys in X makes the old ones stop working. Paste the new keys into LazyRelay to reconnect.

Keeping your keys safe

  • The four keys give full control of your X account, so treat them like a password.
  • LazyRelay support will never ask you to send your keys in chat, by email or in any other way. They go only into the Connect X page.
  • LazyRelay stores the keys encrypted, and you can remove them at any time by disconnecting X in Social Platforms. To cut off access completely, also regenerate the keys in the X Developer Console.
