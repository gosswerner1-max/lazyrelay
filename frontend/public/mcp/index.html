The part most AI-agent schedulers skip

Almost every "post from your AI agent" integration stops at the API call — your agent asks for a post, the API says 200 OK, and that's treated as done. It isn't. Rate limits, silent moderation holds, and platform-side failures can all eat a "successful" request. LazyRelay's list_scheduled_posts tool returns real Proof-of-Publish status, so you can ask your agent to check whether a post actually went live, not just whether the request was accepted.

Questions

What is MCP?

Model Context Protocol — an open standard that lets an AI agent call real tools in another app, instead of you copy-pasting between a chat window and a dashboard. LazyRelay's MCP server exposes the six tools above to any agent that speaks it.

Do I need a paid plan?

Yes. AI-agent / MCP access is included on every paid plan — Starter, Pro, Business, Agency, and Agency Plus — at no extra cost. It isn't available on the Free plan.

Local package or hosted connector — which do I use?

If your tool has a "remote connector" or "custom MCP server" setting that takes just a URL, use the hosted option and sign in with your LazyRelay account — nothing to install. If it only supports a local config file (most editors and CLIs), use the @lazyrelay/mcp-server package with an API key instead. Each guide below says which applies.

What can an agent actually do with this?

Exactly the nine tools listed above — schedule, publish immediately, edit, list, cancel, and check the real status of posts, plus list workspaces, pull analytics, and read recent comments. It can't change your account settings, billing, or connected-account credentials.

My tool isn't on this list — will it still work?

Possibly. LazyRelay's hosted MCP server follows the standard OAuth-secured remote MCP spec, so any client that supports adding a custom remote MCP connector should be able to use it, even without a guide written for it yet. Point it at https://lazyrelaylazyrelay-backend.onrender.com/mcp and see.

Don't have a LazyRelay account yet? AI-agent / MCP access is included on every paid plan — Starter, Pro, Business, Agency, and Agency Plus.
