STEP 1: SETUP (ONE TIME ONLY)
================================================================================

1. Copy credentials.example.json to credentials.local.json:
   cp credentials.example.json credentials.local.json

2. Open credentials.local.json and fill in the password for each mailbox:
   "pass": "YOUR_PASSWORD_HERE"
   (Same password for all four mailboxes per your setup)

3. Save the file (keep it secret, it's gitignored)

TROUBLESHOOTING
================================================================================

ERROR: "Missing credentials.local.json"
  → Copy credentials.example.json to credentials.local.json and fill password

ERROR: "Cannot connect to IMAP"
  → Check IMAP is enabled in cPanel
  → Verify password is correct (test in Thunderbird first)

ERROR: "Active Priorities.md not found"
  → Vault location is: C:\Users\werne\Documents\werner-brain
  → If moved, update VAULT_PATH in data-collector.js

NO UNREAD EMAILS:
  → Normal if you've read everything
  → Only unread emails appear in dashboard
  → Check Thunderbird to see all mail

JSON FILE IS EMPTY:
  → Check output directory exists and is writable
  → Default output: C:\Users\werne\Documents\werner-brain\
